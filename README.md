### `01` — About

I'm studying Computer Science and Health Informatics at the University of Basrah, and most of what I build lives in the overlap between the two: software for handling healthcare data, and pipelines for making sense of biological data that doesn't arrive pre-cleaned.

Day to day, that means writing desktop and web applications that simplify healthcare data management, and building processing pipelines for genomic data — single-cell RNA sequencing, mainly — from raw output to something a researcher can actually use. I care less about which stack gets the credit and more about whether the pipeline runs clean and the interface stays out of the way.

Lately that work happens as much in RStudio and Bioconductor as in a code editor, and increasingly involves figuring out where AI-assisted development actually earns a place in the workflow instead of just being bolted on.

Off the clock: video editing, drone photography, and enough hours in games that I've started calling it research.
